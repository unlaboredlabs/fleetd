Export everything you have stored about me in memory, and any context you've learned about me from our past conversations. I'm moving it to fleetd, the assistant that runs my projects. Keep my own words where you can, especially for instructions and preferences.

## Categories (in this order)

1. **Instructions**: rules I've explicitly asked you to follow from now on: tone, format, style, "always do X", "never do Y", and corrections to how you work. Only rules from your stored memories, not one-off requests from a single conversation.

2. **Identity**: name, location, languages, education, family, relationships and personal interests.

3. **Career**: current and past roles, companies, and skill areas.

4. **Projects**: projects I've meaningfully built or committed to, ideally one entry each: what it does, where it stands, and the key decisions. Start the entry with the project's name.

5. **Preferences**: opinions, tastes and ways of working that hold broadly: tools, languages, design, writing.

## Format

A heading for each category. Under it, one entry per line, oldest first:

[YYYY-MM-DD] - The entry.

Use [unknown] when you don't know the date. Leave out passwords, API keys, tokens and anything else secret.

## Output

- Put the whole export in a single code block, so it copies in one go.
- After the code block, say whether this is the complete set or whether more remains.
