fleetd

An open-source software factory that runs on your own machines.

A hub drives Claude Code through stock T3 Code on every machine you own: one lead per project, tasks with checks, a merge train, and a native app that asks you only when it matters.

curl -fsSL https://fleetd.sh | sh

macOS and Linux. Installs the fleetd CLI and the desktop app into your home directory. Then run fleetd init. Read the script.
