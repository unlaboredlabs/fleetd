    Get started

    Quick start

    fleetd runs Claude Code on your machines: you type what you want, and it plans the work, runs the agents, opens pull requests it has checked, and asks you only about real decisions.

    You need: macOS or Linux x64, the claude CLI logged in (fleetd uses your own claude setup, including any proxy in ~/.claude/settings.json), git, and gh for pull requests. About a minute later the hub runs on this machine, the app is paired, and you type your first order.

    1. Install and set up#

    On the always-on machine that will be your hub:

    curl -fsSL https://fleetd.sh | sh

    It installs fleetd and starts the setup wizard, fleetd init. Enter takes the default at each question, and a ✗ line ends with the command that fixes it. Run fleetd init again at any time: it keeps what works and repairs the rest. curl -fsSL https://fleetd.sh | sh -s -- --no-init only installs.

    2. Send your first order#

    On the hub machine, if it has a desktop, the app is installed too and pairs by itself when you open it. To work from another computer, install fleetd there without the wizard and open the app:

    curl -fsSL https://fleetd.sh | sh -s -- --no-init
open ~/Applications/fleetd.app                    # macOS
~/.local/share/fleetd/app/fleetd-app &            # Linux (or "fleetd" in your app menu)

    Enter the hub address and the pairing code fleetd init printed. Codes last 15 minutes; fleetd pair on the hub prints a new one. The app opens on the board, ready to type: enter an order, such as fix the typo in the README, and press Enter.

    The order starts the project's lead, which answers with a brief and starts work. Its questions land in the inbox (⌘I, Ctrl+I on Linux).
