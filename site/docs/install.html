Install

You’ll install fleetd with one command. It works the same on every machine.

In a terminal, the installer then starts the setup wizard, fleetd init. Continue with Quick start.

Requirements

Section titled “Requirements”
Needed on Notes
macOS (Apple silicon or Intel) or Linux x64 every machine The desktop app needs macOS 12 or newer. On an older Mac the installer stops without changing anything; install the CLI only with --no-app.
claude CLI, logged in every machine that runs agents Your own Claude Code login. fleetd init checks it.
git the hub
gh CLI, logged in the hub fleetd opens and merges pull requests with it.

fleetd init checks each one and prints the install command for anything missing.

What gets installed

Section titled “What gets installed”
  • macOS
  • Linux
What Where
The CLI ~/.fleetd/bin/fleetd, linked from ~/.local/bin/fleetd
The desktop app ~/Applications/fleetd.app
What Where
The CLI ~/.fleetd/bin/fleetd, linked from ~/.local/bin/fleetd
The desktop app (only with a display) ~/.local/share/fleetd/app/fleetd-desktop.AppImage, with an entry in your app menu
  • The installer needs no sudo.
  • Every download is checked against the release’s SHA256SUMS.
  • Running it again replaces what it installed.
  • Only fleetd init sets up services.
  • The desktop app updates itself. Installed over an earlier fleetd app, it replaces it and keeps its pairing.

To read the script first, open fleetd.sh/install.sh.

Options

Section titled “Options”

Pass options after sh -s --:

Option Does
--app Install the desktop app on Linux even without a display.
--no-app Install the CLI only.
--no-init Install, but don’t start the setup wizard.
--join <url> --code <code> Install, then join that hub as a worker instead of starting the wizard. Takes --machine-id, --git-identity and --rejoin too. fleetd pair --worker prints this command; see Add a machine the hub can’t reach.
--uninstall Remove the CLI and the app. See Updating & uninstall.

Build from source

Section titled “Build from source”

With a Rust toolchain:

The CLI is target/release/fleetd. Copy it to ~/.local/bin/fleetd, or run it from there. A worker you add with fleetd machine add gets a copy of the hub’s binary, so build once on the hub. Building the desktop app is covered in CONTRIBUTING.
