fleetd runs Claude Code on your own machines. You type what you want; fleetd plans the work, runs the agents, opens
pull requests it has checked, and asks you only about real decisions.

## Start here

1. [Install](/docs/install): one command puts the CLI and the desktop app on a machine.
2. [Quick start](/docs/quick-start): set up the hub and send your first order.
3. [Concepts](/docs/concepts): the hub, nodes, leads and orders on one page.
